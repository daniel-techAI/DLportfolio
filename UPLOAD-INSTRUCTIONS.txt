DLPORTFOLIO — MANUAL GITHUB UPLOAD

1. Extract DLportfolio.zip.
2. Enter the extracted DLportfolio folder.
3. Open: https://github.com/daniel-techAI/DLportfolio
4. Click Add file > Upload files.
5. Upload the CONTENTS of the folder, not the ZIP itself.
6. Confirm that index.html is visible at the repository root.
7. Commit directly to main.
8. Open Settings > Pages.
9. Select Deploy from a branch.
10. Select main and / (root), then Save.
