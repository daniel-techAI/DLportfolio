MANUAL PHONE UPLOAD
1. Open https://github.com/daniel-techAI/DLportfolio
2. Open the Code tab.
3. Choose Add file -> Upload files.
4. Upload all files and folders from inside this DLportfolio folder.
5. Commit directly to main.
6. Open Settings -> Pages.
7. Choose Deploy from a branch -> main -> /(root) -> Save.
8. Open https://daniel-techai.github.io/DLportfolio/ after the Pages deployment finishes.

TERMINAL OPTION
Run: ./publish.sh
This requires Git and GitHub authentication on the device.
